# Rewrite in plain language

Use this when a paragraph is true but heavy.

```text
Rewrite the text so a tired colleague can read it once.
Keep every factual claim.
Cut throat-clearing and filler.
Do not add examples I did not provide.
Return only the rewritten paragraph.
```

If the source is already plain, say so instead of decorating it.
